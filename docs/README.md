# Threadbox documentation

Product and architecture documents. All are drafts describing intended direction; none of them
describes shipped behaviour unless it says so.

- `implementation-plan.md` - the ordered build plan for the desktop meeting agent, and what is
  deliberately out of scope for now.
- `domain-model.md` - organisations, projects, people, documents, and what sharing between projects
  means for a single user.
- `model-providers.md` - speech recognition and language model options, including why signing in to a
  consumer chat account is not among them.
- `meeting-agent-plan.md` - recording meetings, producing notes and creating tasks from them, with what
  each platform can and cannot do.
- `vocabulary-domain.md` - domain terminology as a first-class feature, used to improve speech
  recognition and to explain unfamiliar subjects.
- `privacy-and-sync-model.md` - the four privacy levels, external language model access, and the data
  layer properties any level above device-only requires.
