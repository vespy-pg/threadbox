# Security policy

Threadbox is currently pre-release software. Please do not publish security vulnerabilities in a public issue. Use GitHub's private vulnerability reporting for this repository so details remain confidential until a fix is available.

The application is local-first and does not intentionally transmit task content, screenshots, or audio to a Threadbox service. The optional speech model download contacts Hugging Face, but recorded audio is processed locally.

Include the affected version, operating system, reproduction steps, and impact in a report. Supported security fixes target the latest published release.
